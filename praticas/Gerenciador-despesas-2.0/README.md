# Gerenciador de Despesas 2.0

Aplicativo React Native/Expo para acompanhar entradas e saídas financeiras de forma simples e visual.

## Funcionalidades

- Saldo total calculado automaticamente.
- Resumo de entradas e saídas do mês.
- Lista de lançamentos com categoria, data e valor.
- Filtros por todos, entradas ou saídas.
- Cadastro de novos lançamentos com tipo, descrição, valor e categoria.
- Exclusão de lançamentos com confirmação.
- Persistência local com AsyncStorage.
- Interface responsiva para mobile e web.

## Como executar

```bash
npm install
npx expo start
```

Para validar no navegador:

```bash
npx expo start --web
```
